# active_tests/

One folder per in-progress experiment (e.g. `active_tests/xgboost-rainfall-lag/`).

When an experiment concludes, move its folder to `../concluded/` and fill
in the **Results** section of its `experiment_blueprint.md` copy before
moving it.

See `../templates/experiment_blueprint.md` for the write-up template, and
the "Experiments Sandbox" section in the repo root's `CLAUDE.md` for the
isolation rules every experiment must follow.
